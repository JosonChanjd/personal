# 关于

这是一个科技风格的个人博客，功能一览：

- 🧠 知识学习与积累
- ✍️ 日常随笔
- 🔍 全文搜索
- 🔗 文章自动关联
- 🗂️ 文档库（NAS）
- 🎨 Markdown 富媒体（视频 / 图片 / 脑图）
- 📈 GitHub 风格更改频次与访问记录

## 技术栈

| 能力 | 实现 |
| --- | --- |
| 静态站点 | VitePress |
| 全文搜索 | VitePress 内置本地搜索 |
| 脑图 / 流程图 | Mermaid |
| 贡献热力图 | 自定义 Vue 组件 + `git log` |
| 访问统计 | 不蒜子（全网）+ localStorage（本机） |
| 文档库 | 自定义 Vue 组件 + 清单生成脚本 |
