## D1: 显示技术进化史

### 1.1 从CRT到Micro-LED：四代显示技术

显示技术的演进是一部人类追求更薄、更亮、更高效的视觉体验的历史。从19世纪末的阴极射线管（CRT）到21世纪的Micro-LED，每一代技术都建立在前一代的物理基础之上，同时突破了其固有局限。

```
  CRT              LCD              OLED            Micro-LED
 (1897)          (1968)           (2007)           (2018)
   │               │                │                 │
   ●───────────────●────────────────●─────────────────●──→ 时间
   │               │                │                 │
 电子束扫描      液晶控光          有机自发光        无机LED阵列
 体积大/有辐射   轻薄/低功耗       对比度∞/柔性      高亮度/长寿命
 荧光粉发光      需背光            寿命有限          成本高

   演进方向: 更薄 · 更亮 · 更高效 · 更柔性
```

**CRT（Cathode Ray Tube，阴极射线管）**

1897年由德国物理学家 Karl Ferdinand Braun 发明，是第一种实用的电子显示器件。其原理是利用电子枪发射电子束，在真空中经电磁场偏转后轰击荧光粉屏，激发荧光粉发光。CRT的物理基础是**阴极射线发光**——电子动能转化为可见光光子。

CRT的主要特征：
- 需要真空玻璃管，体积庞大、重量高
- 电子束扫描速度有限，大尺寸难以实现高分辨率
- 荧光粉余辉特性限制了响应速度
- 存在X射线辐射和电磁辐射

**LCD（Liquid Crystal Display，液晶显示）**

1968年美国RCA实验室首次演示液晶显示，开启了平板显示时代。LCD不自身发光，而是通过液晶分子在外加电场下的排列变化，控制背光源透过偏振片的光量。

LCD的核心物理原理：
- **偏振光控制**：利用偏振片将自然光变为线偏振光
- **液晶旋光效应**：TN（Twisted Nematic）模式下液晶分子自然扭曲90°，使偏振面旋转
- **电场调控**：外加电压改变液晶分子排列，控制偏振面旋转程度
- **马吕斯定律**：通过检偏器的光强 $I = I_0 \cos^2\theta$

**OLED（Organic Light-Emitting Diode，有机发光二极管）**

1987年 Kodak 的邓青云博士发明了双层有机发光器件。OLED的每个像素自发光，无需背光。其原理是有机材料在电流驱动下发生电致发光——电子和空穴在发光层复合，释放光子。

OLED的优势在于：
- 像素级控光，对比度理论无穷大
- 响应速度极快（微秒级）
- 可实现柔性、透明显示
- 无需背光模组，更轻薄

**Micro-LED**

Micro-LED是将无机LED芯片微缩至微米级（通常<50μm），通过巨量转移技术将红、绿、蓝三色LED芯片阵列排列在基板上。它兼具OLED的自发光优势和LED的高效率、长寿命特性，被认为是终极显示技术。

### 1.2 LCD面板结构解析

LCD面板是一个精密的光学系统，由多层功能薄膜和液晶层叠加构成：

```
  ┌───────────────────────────────────────────────────┐
  │  ⑧ 上偏振片(检偏器)    透光轴: 水平 →            │ ← 最终出射光
  ├───────────────────────────────────────────────────┤
  │  ⑦ 彩色滤光片         ┌───┬───┬───┐              │
  │   (Color Filter)       │ R │ G │ B │ 子像素      │ ← RGB彩色光
  │                        └───┴───┴───┘              │
  ├───────────────────────────────────────────────────┤
  │  ⑥ 公共电极(ITO)       透明导电层                  │
  ├───────────────────────────────────────────────────┤
  │                                                   │
  │  ⑤ 液晶层(LC Layer)   ↻ ↻ ↻ ↻ ↻ ↻              │ ← 受控偏振光
  │     TN模式: 分子自然扭曲90°                        │
  ├───────────────────────────────────────────────────┤
  │  ④ 像素电极(ITO)       透明导电层, 施加电场        │
  ├───────────────────────────────────────────────────┤
  │  ③ TFT基板(玻璃)       薄膜晶体管阵列, 逐像素控制  │
  ├───────────────────────────────────────────────────┤
  │  ② 下偏振片(起偏器)    透光轴: 垂直 ↑             │ ← 线偏振光
  ├───────────────────────────────────────────────────┤
  │  ① 背光模组(Backlight) LED光源, 提供均匀白光       │ ← 白光
  └───────────────────────────────────────────────────┘
        ↑
     光传播方向
```

各层功能说明：

| 层次 | 名称 | 功能 |
|------|------|------|
| 1 | 背光模组 | LED光源，提供均匀白光 |
| 2 | 下偏振片（起偏器） | 将自然光变为线偏振光 |
| 3 | TFT基板 | 薄膜晶体管阵列，逐像素电压控制 |
| 4 | 像素电极（ITO） | 透明导电层，向液晶施加电场 |
| 5 | 液晶层 | 电场控制分子排列，调控偏振面 |
| 6 | 公共电极（ITO） | 与像素电极形成均匀电场 |
| 7 | 彩色滤光片 | R/G/B子像素，将白光分为三基色 |
| 8 | 上偏振片（检偏器） | 与起偏器正交，输出调制后的光 |

> **关键洞察**：LCD本质上是"光调制器"而非"光源"。它通过控制光的偏振状态来调节每个子像素的亮度，再通过彩色滤光片实现彩色显示。这决定了LCD必须依赖背光，也限制了其对比度上限。

```
  色彩还原          ███████    ████████    █████████

```

**LCD的优势：**

1. **制造成熟度高**：经过数十年发展，产业链完善，大尺寸面板成本低
2. **寿命长**：无机材料为主，无有机材料老化问题
3. **峰值亮度高**：背光可持续增强，Mini-LED背光可达2000+ nits
4. **无烧屏风险**：不会像OLED那样因静态画面导致像素老化不均

**LCD的劣势：**

1. **对比度受限**：背光始终存在，暗态漏光不可避免（典型对比度1000:1~5000:1）
2. **响应速度慢**：液晶分子物理旋转需要毫秒级时间，运动模糊明显
3. **色域有限**：彩色滤光片的光谱特性限制了色域覆盖（通常约72% NTSC）
4. **功耗依赖背光**：无论显示内容如何，背光持续消耗能量
5. **可视角度受限**：TN模式尤其严重，IPS/VA有所改善但仍不及OLED

**LCD的市场定位：**

LCD在大尺寸（>55英寸）电视、桌面显示器、笔记本电脑等场景仍占据主导地位。其在大尺寸成本优势、高亮度需求场景（如HDR显示、户外广告屏）以及无烧屏需求的专业应用（医疗、监控）中具有不可替代的优势。

## D2: 光的波动性与粒子性

### 2.1 电磁波的基本参量

光是一种电磁波，其电场 $\vec{E}$ 和磁场 $\vec{B}$ 相互正交，且均垂直于传播方向。光波的所有基本特性都可以用四个参量完整描述：**频率**、**波长**、**振幅**和**相位**。

```
  振幅A ───── ╮           ╭───── ╮           ╭─────
  (Amplitude) │           │       │           │
              │           │       │           │
  平衡线 ─────┼───────────┼───────┼───────────┼─────→ 传播方向
              │           │       │           │
              ╭─╮       ╭─╯       ╰─╮       ╭─╯
              ╯ ╰───────╯           ╰───────╯
              ├─── 波长 λ ─────────┤
              │   (Wavelength)     │
              ├── 周期 T = 1/f ───┤
              │   (Period)         │

  ● 相位 φ (Phase): 描述波在振动周期中的位置, 单位rad

  ┌──────────────────────────────────────────────────┐
  │  公式:  E(x,t) = A · cos(kx - ωt + φ)           │
  │  光强:  I ∝ A²    (振幅的平方决定亮度)            │
  │  光速:  c = λ · f ≈ 3×10⁸ m/s                   │
  └──────────────────────────────────────────────────┘
```

电磁波的电场分量可用以下方程描述：

$$E(x,t) = A \cos(kx - \omega t + \varphi)$$

其中各参量的物理意义：

**频率（Frequency, $f$）**

单位时间内波振动的次数，单位为赫兹（Hz）。频率决定了光的颜色：
- 红光：约 $4.3 \times 10^{14}$ Hz（波长约700nm）
- 绿光：约 $5.5 \times 10^{14}$ Hz（波长约550nm）
- 蓝光：约 $6.7 \times 10^{14}$ Hz（波长约450nm）

频率与角频率的关系：$\omega = 2\pi f$

**波长（Wavelength, $\lambda$）**

相邻两个同相位点之间的距离。波长与频率的关系由光速决定：

$$c = \lambda \cdot f$$

其中 $c \approx 3 \times 10^8$ m/s 为真空光速。可见光波长范围为380~780nm。

**振幅（Amplitude, $A$）**

电场强度的最大值。光强（单位面积上的光功率）与振幅的平方成正比：

$$I = \frac{1}{2} c \varepsilon_0 A^2 \propto A^2$$

在显示技术中，振幅直接对应像素的亮度。LCD通过控制透过光的振幅来调节亮度，OLED通过控制发光强度来改变振幅。

**相位（Phase, $\varphi$）**

描述波在某一时刻处于振动周期的哪个位置，单位为弧度（rad）。相位是波动最本质的参量之一。两束频率相同、相位差恒定的光波可以发生干涉，这是全息显示和3D显示的物理基础。

### 2.2 电磁波的三维结构

```
  电场 E (Y轴方向)
    ↑
    │  ╭───╮       ╭───╮       ╭───╮
    │ ╱     ╲     ╱     ╲     ╱     ╲    ← E场(电场)
    │╱       ╲   ╱       ╲   ╱       ╲
    ●─────────●──●─────────●──●─────────●──→ 传播方向 z (光速c)
    │╲       ╱   ╲       ╱   ╲       ╱
    │ ╲     ╱     ╲     ╱     ╲     ╱    ← B场(磁场, 垂直于E)
    │  ╰───╯       ╰───╯       ╰───╯
    │
    └──────── 磁场 B (Z轴方向, 垂直纸面向里/外)

  · E ⊥ B ⊥ 传播方向  (横波)
  · E × B 的方向 = 传播方向
  · E 和 B 同相位变化
```

电磁波是横波，其电场和磁场满足以下正交关系：
- 电场 $\vec{E}$ ⊥ 磁场 $\vec{B}$
- $\vec{E} \times \vec{B}$ 的方向即传播方向
- $\vec{E}$ 和 $\vec{B}$ 同相位变化

### 2.3 波粒二象性

光同时具有波动性和粒子性，这一性质称为**波粒二象性**（Wave-Particle Duality）。这一概念是量子力学的基石之一。

```
  ┌─────────────────────────┐       ┌─────────────────────────┐
  │   波动性 (Wave)          │       │   粒子性 (Particle)      │
  │                         │ ←──→ │                         │
  │  ~~~~~~~~~~~~~~~~~~~~   │ 互补  │    o   o   o   o        │
  │  ~~~~~~~~~~~~~~~~~~~~   │ 共存  │      o   o   o          │
  │  ~~~~~~~~~~~~~~~~~~~~   │       │    o   o   o   o        │
  │                         │       │                         │
  │  · 干涉 (明暗条纹)       │       │  · 光电效应 (释放电子)   │
  │  · 衍射 (光绕过障碍物)   │       │  · 康普顿散射            │
  │  · 偏振 (振动方向选择)   │       │  · 离散光子量子           │
  │  · 连续能量分布          │       │  · E = hf,  p = h/λ     │
  └─────────────────────────┘       └─────────────────────────┘

  ┌───────────────────────────────────────────────────────────┐
  │  联系桥梁:  E = hf = hc/λ      p = h/λ                   │
  │  普朗克常数: h = 6.626 × 10⁻³⁴ J·s                      │
  └───────────────────────────────────────────────────────────┘

  显示应用: OLED/LED电致发光 → 粒子性 (电子-空穴复合释放光子)
           LCD偏振控制/导光板 → 波动性 (偏振/干涉/全反射)
```

**波动性的体现：**
- 干涉：两束相干光叠加产生明暗条纹
- 衍射：光绕过障碍物或通过狭缝时弯曲传播
- 偏振：电场矢量的振动方向可以被选择性透过

**粒子性的体现：**
- 光电效应：光照射金属表面释放电子（爱因斯坦因此获1921年诺贝尔奖）
- 康普顿散射：X射线与电子碰撞后波长改变
- 光子能量离散：每个光子携带的能量为 $E = hf$

**联系波与粒子的桥梁：**

$$E = hf = \frac{hc}{\lambda}, \quad p = \frac{h}{\lambda}$$

其中 $h = 6.626 \times 10^{-34}$ J·s 为普朗克常数。

> **在显示技术中的应用**：OLED和LED的电致发光本质上是粒子性的体现——电子和空穴复合释放离散光子。而LCD的偏振控制、导光板的匀光设计则主要利用波动性。理解波粒二象性是掌握所有显示技术物理基础的前提。

| 波长范围 | 颜色 | 显示应用 |

## D3: 偏振光物理

### 3.1 偏振的概念

偏振是横波特有的性质。对于电磁波而言，偏振描述的是电场矢量 $\vec{E}$ 的振动方向。自然光（如太阳光、灯光）是非偏振光——电场在垂直于传播方向的所有方向上均匀振动。

偏振光物理是LCD技术的核心理论基础。没有偏振光控制，就没有现代液晶显示。

### 3.2 线偏振光

当电场矢量只沿一个固定方向振动时，称为**线偏振光**（Linearly Polarized Light）。线偏振光可通过偏振片（Polarizer）从自然光中获得。

```
  自然光(非偏振)          偏振片            线偏振光          检偏器(旋转θ)        出射光
                         (起偏器)
   ↑↓ ←→                ┌─────┐            ↑                 ┌─────┐
   ↗↖ ↑↓                │ | | │            ↑                 │  /  │           ↗
   ←→ ↑↓ ↗↖    ──→      │ | | │   ──→      ↑      ──→        │  /  │   ──→    ↗
   ↑↓ ←→ ↗↖             │ | | │            ↑                 │  /  │        I=I₀cos²θ
   (各方向振动)           └─────┘          (单一方向)          └─────┘
                         透光轴:垂直↑                         透光轴:旋转θ角

  自然光 → [起偏器] → 线偏振光 → [检偏器旋转θ] → I = I₀ cos²θ
  理想偏振片透过率: 50% (实际约42%~46%)
```

偏振片内部含有定向排列的二向色性分子，只允许电场沿特定方向（透光轴）振动的光通过，其他方向的光被吸收。

**偏振片的工作原理：**
1. 自然光包含所有振动方向，各方向强度相等
2. 通过偏振片后，只有沿透光轴方向振动的光通过
3. 理想偏振片透过50%的光（实际约42%~46%）
4. 出射光变为线偏振光

### 3.3 圆偏振与椭圆偏振

```
  迎光观察(截面图):               沿传播方向(侧视图):

      ╭───╮                          E矢量末端轨迹:
     ╱     ╲                         ╭───╮
    │   ●   │  ← E矢量匀速旋转        │ · │ · │
     ╲     ╱                         │   ●   │ ← 螺旋传播
      ╰───╯                          │ · │ · │
     圆偏振光                          ╰───╯
     (振幅恒定)                         → z (传播方向)

  右旋(RCP): 迎光看E顺时针旋转         Ex = A·cos(kz - ωt)
  左旋(LCP): 迎光看E逆时针旋转         Ey = A·sin(kz - ωt)  (右旋)

  条件: 两束等幅正交线偏振光, 相位差 = ±90°
```

当两束振幅相等、相位差为 $\pm\pi/2$ 的正交线偏振光叠加时，电场矢量的端点轨迹为圆形，形成**圆偏振光**：

$$E_x = A\cos(kz - \omega t), \quad E_y = A\sin(kz - \omega t)$$

- **右旋圆偏振光（RCP）**：迎光观察时，E矢量顺时针旋转
- **左旋圆偏振光（LCP）**：迎光观察时，E矢量逆时针旋转

当两束正交线偏振光振幅不等或相位差不等于 $\pi/2$ 时，形成**椭圆偏振光**。

```
  线偏振光           圆偏振光           椭圆偏振光
  (Linear)           (Circular)         (Elliptical)

    │ ↑               ╭───╮              ╭─────╮
    │ │              ╱     ╲            │       │
    │ │             │   ●   │           │   ●   │
    │ │              ╲     ╱            │       │
    │ ↑               ╰───╯              ╰─────╯
    │                 E匀速旋转           E旋转但
  固定方向            振幅恒定            振幅周期变化

  E场沿固定          两正交等幅          两正交不等幅
  方向振动            相位差±90°          或任意相位差
```

**偏振光类型总结：**

| 类型 | E矢量端点轨迹 | 产生条件 | 显示应用 |
|------|--------------|----------|----------|
| 线偏振 | 直线 | 单一方向振动 | LCD偏振片 |
| 圆偏振 | 圆 | 等幅正交、相位差±90° | 3D显示（圆偏振眼镜） |
| 椭圆偏振 | 椭圆 | 不等幅正交或任意相位差 | 液晶补偿膜 |

> **3D显示应用**：RealD 3D影院系统使用圆偏振光实现立体显示。放映机交替投射左旋和右旋圆偏振光构成的左右眼画面，观众佩戴圆偏振眼镜分别接收对应眼别的画面。

### 3.4 马吕斯定律（Malus's Law）

当线偏振光通过第二个偏振片（检偏器）时，透射光强与两偏振片透光轴夹角的关系由**马吕斯定律**描述：

```
  I/I₀ (归一化光强)
  1.0 │ ●━━━━━━━                       ●━━━━━━━
      │         ╲                       ╱
  0.8 │          ╲                     ╱
      │           ╲                   ╱
  0.6 │            ╲                 ╱
      │             ╲               ╱
  0.4 │              ╲             ╱
      │               ╲           ╱
  0.2 │                ╲         ╱
      │                 ╲       ╱
  0.0 │──────────────────●━━━━━●──────────────────
      │   0°   45°   90°  135° 180°  225°  270°  315°  360°
      └─────────────────── θ (偏振片夹角) ─────────────────→

      I = I₀ cos²θ

  0°  → I₀ (100%)    完全透过 (平行)
  45° → 0.5 I₀ (50%) 一半透过
  90° → 0 (0%)       完全阻挡 (正交)
  180°→ I₀ (100%)    周期重复

  检偏器原理:
    起偏器透光轴 ↑     检偏器透光轴 ↗
    E场分量 = I₀cosθ → 透过 = I₀cos²θ
```

$$\boxed{I = I_0 \cos^2\theta}$$

其中：
- $I_0$ 为入射线偏振光的光强
- $\theta$ 为起偏器与检偏器透光轴之间的夹角
- $I$ 为透过检偏器的光强

**关键角度值：**

| 夹角 θ | cos²θ | 透射比 I/I₀ | 物理含义 |
|---------|-------|-------------|----------|
| 0° | 1.000 | 100% | 完全透过（正交平行） |
| 30° | 0.750 | 75% | 大部分透过 |
| 45° | 0.500 | 50% | 一半透过 |
| 60° | 0.250 | 25% | 少量透过 |
| 90° | 0.000 | 0% | 完全阻挡（正交偏振片） |

> **LCD中的马吕斯定律**：LCD的核心原理就是通过液晶分子的旋光效应改变偏振方向，从而控制通过检偏器的光量。不加电压时，TN液晶使偏振面旋转90°，偏振片正交配置下光完全透过（亮态）；加电压时液晶分子沿电场排列，偏振面不旋转，检偏器完全阻挡（暗态）。每个子像素的灰阶就是通过精确控制液晶扭转角度实现的连续 $\cos^2\theta$ 调制。

## D4: 几何光学在显示中的应用

### 4.1 折射与斯涅尔定律

当光从一种介质传播到另一种介质时，由于两种介质中光速不同，光的传播方向在界面处发生改变，这一现象称为**折射**。

```
          介质1 (n₁)  空气 n ≈ 1.0

              入射光
                ╲
                  ╲        θ₁ (入射角)
                    ╲     ╱
                      ╲ ╱
              ─────────╳──────────  界面
                      ╱ ╲
                    ╱   θ₂ (折射角)
                  ╱
                ●  ← 折射光 (弯向法线, 因 n₂ > n₁)
              ╱
            ╱
          介质2 (n₂)  玻璃 n ≈ 1.5

  ╎ = 法线    ╲ = 入射光    ╱ = 折射光

  ┌────────────────────────────────────────┐
  │  斯涅尔定律:  n₁ sin θ₁ = n₂ sin θ₂   │
  │  折射率:      n = c / v                │
  │  光疏→光密:   θ₂ < θ₁ (弯向法线)      │
  │  光密→光疏:   θ₂ > θ₁ (远离法线)      │
  └────────────────────────────────────────┘
```

折射遵循**斯涅尔定律**（Snell's Law）：

$$\boxed{n_1 \sin\theta_1 = n_2 \sin\theta_2}$$

其中：
- $n_1, n_2$ 分别为两种介质的折射率
- $\theta_1$ 为入射角（入射光与法线的夹角）
- $\theta_2$ 为折射角（折射光与法线的夹角）

**折射率与光速的关系：**

$$n = \frac{c}{v}$$

其中 $c$ 为真空光速，$v$ 为光在该介质中的速度。

**常见介质折射率：**

| 介质 | 折射率 n | 在显示中的应用 |
|------|---------|---------------|
| 真空/空气 | 1.000 | 外部环境 |
| 水 | 1.333 | 清洁/散热 |
| 普通玻璃 | 1.52 | 基板、盖板 |
| 蓝宝石玻璃 | 1.77 | 高端盖板 |
| 液晶（寻常光） | 1.5~1.7 | LCD液晶层 |
| ITO（透明电极） | ~2.0 | 导电层 |
| 光学胶（OCA） | 1.47~1.49 | 层间贴合 |

**折射规律总结：**
- 光从光疏介质（低 $n$）→ 光密介质（高 $n$）：折射角 < 入射角（弯向法线）
- 光从光密介质→光疏介质：折射角 > 入射角（远离法线）

### 4.2 全反射

当光从光密介质射向光疏介质时，如果入射角超过某一临界值，光将完全反射回原介质，不发生折射，这一现象称为**全反射**（Total Internal Reflection, TIR）。

```
  (a) θ₁ < θc           (b) θ₁ = θc             (c) θ₁ > θc
  一般折射               临界状态                 全反射

  玻璃 n=1.5             玻璃 n=1.5               玻璃 n=1.5
    ╲    ╎                 ╲    ╎                   ╲    ╎
     ╲θ₁ ╎                  ╲θc ╎                    ╲θ₁ ╎
      ╲  ╎                   ╲  ╎                     ╲  ╎
  ═════╲═╎══════       ═══════╲═╎══════        ════════╲═╎══════
        ╲ ╎ θ₂                  ╲ ╎ θ₂=90°               ╲ ╎
         ●←折射光                 ─ ─ ─ ─ ←沿界面           ●←反射光
          ╲                                             ╱
           ╲                                          ╱
            ╲                                       ╱
  空气 n=1.0              空气 n=1.0               空气 n=1.0
  (有折射光)              (折射光沿界面滑行)         (无折射光,全部反射)

  ┌─────────────────────────────────────────────────────┐
  │  临界角公式:  sin θc = n₂ / n₁   (n₁ > n₂)        │
  │                                                     │
  │  例: 玻璃→空气  sin θc = 1.0 / 1.5 = 0.667         │
  │      θc = arcsin(0.667) ≈ 41.8°                   │
  │                                                     │
  │  当入射角 θ₁ > θc 时, 发生全反射                   │
  │  光导纤维利用全反射原理传输光信号                   │
  └─────────────────────────────────────────────────────┘
```

**临界角**的计算公式：

$$\sin\theta_c = \frac{n_2}{n_1} \quad (n_1 > n_2)$$

以玻璃-空气界面为例：

$$\sin\theta_c = \frac{1.0}{1.5} = 0.667, \quad \theta_c = \arcsin(0.667) \approx 41.8°$$

当入射角 $\theta_1 > \theta_c$ 时，发生全反射。

> **全反射在显示中的应用**：
> 1. **导光板（Light Guide Plate, LGP）**：LCD背光模组的核心部件。LED侧入式光线在导光板内部通过全反射传播至远端，再通过底面的微结构打破全反射，使光从表面均匀射出。
> 2. **光导纤维**：利用纤芯-包层的全反射传输光信号，用于显示信号传输和远距离通信。
> 3. **全反射棱镜（TIR Prism）**：投影仪光路中使用全反射棱镜实现光路折叠，缩小光学引擎体积。

### 4.3 LCD中的光学原理综合应用

LCD面板是一个将偏振光物理、几何光学和色度学完美结合的光学系统：

```
  光传播方向 ↑

  ───────────────────────────────────────────── ⑧ 上偏振片(检偏器)
                                                透光轴: 水平 →
  ───────────────────────────────────────────── ⑦ 彩色滤光片  R|G|B
                                                子像素

  ───────────────────────────────────────────── ⑥ 公共电极(ITO)

     ↻   ↻   ↻   ↻   ↻   ↻   ↻   ↻   ↻       ← TN液晶分子
  ───────────────────────────────────────────── ⑤ 液晶层       自然扭曲90°
     ↻   ↻   ↻   ↻   ↻   ↻   ↻   ↻   ↻          引导偏振面旋转90°

  ───────────────────────────────────────────── ④ 像素电极(ITO)
  ───────────────────────────────────────────── ③ TFT基板(玻璃)

  ───────────────────────────────────────────── ② 下偏振片(起偏器)
                                                透光轴: 垂直 ↑
  ───────────────────────────────────────────── ① 背光模组(LED)
              ↑
            白光

  ═══════════════════════════════════════════════════════
  不加电压(亮态): 液晶扭曲90° → 偏振面垂直→水平 → 通过检偏器 = 白
  加电压(暗态):   液晶垂直排列 → 偏振面不转  → 被检偏器阻挡 = 黑
  灰阶:           部分旋转 → I = I₀cos²θ → 连续亮度控制
  ═══════════════════════════════════════════════════════

  应用原理:
    · 导光板全反射     → D4 全反射
    · 偏振片起偏/检偏   → D3 线偏振
    · 液晶旋光+cos²θ   → D3 马吕斯定律
    · RGB彩色滤光      → D5 色域混色
```

**光在LCD中的完整传播路径：**

1. **背光产生**：LED发出白光，经导光板匀光（利用**全反射**原理）
2. **起偏**：通过下偏振片变为线偏振光（**偏振光物理**）
3. **液晶调制**：
   - **不加电压（亮态）**：TN液晶分子从下到上自然扭曲90°，引导偏振面旋转90°，使偏振方向与上偏振片平行，光完全透过（马吕斯定律 $\cos^2 0° = 1$）
   - **加电压（暗态）**：液晶分子沿电场垂直排列，偏振面不旋转，与上偏振片正交，光完全阻挡（$\cos^2 90° = 0$）
   - **中间电压（灰阶）**：液晶部分旋转，偏振面旋转角度在0°~90°之间，透过率由 $\cos^2\theta$ 决定（**马吕斯定律**）
4. **彩色化**：通过彩色滤光片分为R/G/B三个子像素
5. **检偏输出**：通过上偏振片输出最终调制后的彩色光

**LCD模式对比：**

| 模式 | 全称 | 液晶排列 | 优势 | 劣势 |
|------|------|----------|------|------|
| TN | Twisted Nematic | 90°螺旋扭曲 | 成本低、响应快 | 可视角度小、色偏 |
| IPS | In-Plane Switching | 平面内旋转 | 可视角度大、色准好 | 透光率低、对比度一般 |
| VA | Vertical Alignment | 垂直排列 | 对比度高、黑色纯净 | 响应较慢、侧视偏色 |
| ADS | Advanced Super Dimension | 高级超维转换 | 高透光率、宽视角 | 成本较高 |

> **关键公式串联**：LCD亮度控制的本质是一个连续的马吕斯定律应用——通过液晶旋光效应改变 $\theta$，从而精确控制每个子像素的透过率 $T = \cos^2\theta$。这意味着LCD的理论最大透光率（不计其他损耗）仅为50%（起偏器损失50%）。

## D5: 色度学基础

### 5.1 CIE 1931色度图

色度学是研究颜色测量与定量描述的科学。1931年国际照明委员会（CIE）建立了基于人眼三色觉特性的颜色描述系统——**CIE 1931 XYZ色空间**。

```
  y (绿)
  0.9 │         ●  380nm (紫)
      │        ╱ ╲              光谱轨迹
  0.8 │       ╱   ╲             (马蹄形边界 =
      │      ╱     ╲            纯单色光坐标)
  0.7 │     ╱  480  ╲              ● 520nm (绿)
      │    ╱   nm    ╲           ╱
  0.6 │   ╱           ╲         ╱
      │  ╱   绿色区域   ╲      ╱
  0.5 │ ╱                ╲   ╱
      │╱                  ● ← D65 白点
  0.4 │             蓝色   │  (0.313, 0.329)
      │             区域   │      红色区域    ● 620nm (红)
  0.3 │                    │    ╱
      │                    │  ╱
  0.2 │                    ● 580nm (橙黄)
      │
  0.1 │
      │
  0.0 └──────────────────────────────────────→ x (红)
      0.0    0.2    0.4    0.6    0.8

  · 边界 = 光谱轨迹 (纯单色光)    ● = 关键波长
  · D65 = 标准白点 (sRGB等标准)
  · 越靠近边界 → 颜色饱和度越高
  · 直线段(紫线)连接 380nm 和 700nm
```

**三刺激值与色度坐标：**

人眼视网膜有三种锥体细胞（L/M/S），分别对长波、中波、短波光敏感。CIE定义了三个色匹配函数 $\bar{x}(\lambda)$、$\bar{y}(\lambda)$、$\bar{z}(\lambda)$，任何光谱分布 $S(\lambda)$ 的颜色可用三刺激值表示：

$$X = k\int S(\lambda)\bar{x}(\lambda)d\lambda$$
$$Y = k\int S(\lambda)\bar{y}(\lambda)d\lambda$$
$$Z = k\int S(\lambda)\bar{z}(\lambda)d\lambda$$

**色度坐标**（归一化表示）：

$$x = \frac{X}{X+Y+Z}, \quad y = \frac{Y}{X+Y+Z}, \quad z = \frac{Z}{X+Y+Z}$$

由于 $x + y + z = 1$，只需 $(x, y)$ 两个坐标即可唯一确定色度。

**CIE 1931色度图的特征：**
- 马蹄形边界为**光谱轨迹**，代表所有纯单色光的色度坐标
- 直线段为"紫线"（连接380nm和700nm），不代表实际光谱
- 内部所有区域代表混合色
- **D65白点**位于 $(0.3127, 0.3290)$，是sRGB等标准白点
- 越靠近边界，颜色饱和度越高（越纯）

### 5.2 CIE 1976均匀色度图

CIE 1931色度图存在一个缺陷：不同区域的颜色感知差异不均匀——绿区放大、蓝区压缩。为此，CIE于1976年提出了改进的均匀色度空间 **CIE 1976 u'v'**：

```
  v'
  0.6 │        ●  光谱轨迹
      │       ╱ ╲
  0.5 │      ╱   ╲
      │     ╱     ╲
  0.4 │    ╱       ╲
      │   ╱    ╭───╮ ╲       ┄┄┄ 虚线圆 = 视觉等色差
  0.3 │  ╱    ╱ D65 ╲ ╲      (CIE 1976 比 1931 更均匀)
      │ ╱    ╰───╯   ╲
  0.2 │╱               ╲
      │
  0.1 │
      │
  0.0 └──────────────────────────→ u'
      0.0    0.2    0.4    0.6

  · 以D65白点为中心的等半径圆 ≈ 等色差
  · 修正了 CIE 1931 中绿区放大、蓝区压缩的问题
```

坐标转换公式：

$$u' = \frac{4x}{-2x + 12y + 3}, \quad v' = \frac{9y}{-2x + 12y + 3}$$

在CIE 1976空间中，以白点为中心的等半径圆近似代表等色差，更适合用于色差评估和显示品质分析。

> **实际意义**：在CIE 1931中，绿区1%的坐标变化人眼几乎无感，而蓝区0.5%的变化就明显可辨。CIE 1976的修正使色差计算更符合人眼感知，广泛应用于显示面板的色差验收标准。

### 5.3 色域标准

色域（Color Gamut）是指显示设备能够呈现的颜色范围，通常在CIE色度图上用三角形表示。三角形的三个顶点对应显示设备R/G/B三基色的色度坐标。

```
  y
  0.8 │           ●NTSC-G
      │          ╱ ╲
  0.7 │         ╱   ╲          ┌─── sRGB ───┐
      │        ╱     ╲        ╱  ╲    ╲     │
  0.6 │       ╱       ╲      ╱    ● D65 ╲    │
      │      ╱  绿色    ╲   ╱   ╱    ╲   ╲  │
  0.5 │     ╱  区域     ╲ ╱  ╱      ╲   ╲  │
      │    ╱              ●             ╲ │
  0.4 │   ╱              │   DCI-P3       │
      │  ╱               │   区域         │
  0.3 │ ╱                │               │
      │╱    蓝色区域      │   红色区域     │
  0.2 │ ●────────────────●───────────────●
      │R-sRGB          B               G-sRGB
  0.1 │
  0.0 └──────────────────────────────────────────→ x
      0.0    0.2    0.4    0.6    0.8

  · ┌─┐ sRGB (~35% NTSC)    面积最小, 通用标准
  · ○ NTSC (100%)           广播电视旧标
  · □ DCI-P3 (~86% NTSC)   数字影院, 高端手机
  · 面积越大 = 可显示颜色范围越广
```

**主流色域标准：**

| 标准 | 基色坐标 (R/G/B) | 白点 | 覆盖NTSC | 典型应用 |
|------|-------------------|------|----------|----------|
| sRGB | (0.64,0.33)/(0.30,0.60)/(0.15,0.06) | D65 | ~35% | 网页、普通显示 |
| NTSC | (0.67,0.33)/(0.21,0.71)/(0.14,0.08) | D65 | 100% | 广播电视（旧标） |
| DCI-P3 | (0.68,0.32)/(0.265,0.69)/(0.15,0.06) | D65 | ~86% | 数字影院、高端手机 |
| Adobe RGB | (0.64,0.33)/(0.21,0.71)/(0.15,0.06) | D65 | ~76% | 专业摄影印刷 |
| Rec.2020 | (0.708,0.292)/(0.170,0.797)/(0.131,0.046) | D65 | ~150% | HDR超高清电视 |

**色域面积与显示能力的关系：**

色域面积越大，显示器能呈现的颜色范围越广。但需注意：
- 色域三角形必须被光谱轨迹包围（不能超出物理极限）
- 色域覆盖是面积比，不代表所有颜色都能准确显示
- Rec.2020色域需要单色激光或量子点才能实现，目前商用显示器尚无法完全覆盖

> **LCD扩展色域的方法**：传统LCD使用白光LED背光+彩色滤光片，色域受限（约72% NTSC）。通过以下技术可扩展色域：
> - **量子点（QD）膜**：将蓝光LED激发量子点发出窄带红绿光，色域可达100%+ NTSC
> - **RGB LED背光**：直接使用R/G/B三色LED，色域可达100%+ NTSC但成本高
> - **荧光粉改进**：使用窄带绿色荧光粉提升绿色纯度

### 5.4 色温与白点

**色温**（Color Temperature）是描述光源颜色的物理量，基于黑体辐射理论。当一个理想黑体被加热到某一温度时，其辐射光的颜色与该光源相同时，该温度即为光源的色温，单位为开尔文（K）。

```
  色温(K)     光色渐变             感觉       典型光源
  ──────────────────────────────────────────────────────
  1000K  ████████████████  橙红 · 极暖   蜡烛 / 火焰
  2700K  ████████████████  暖黄 · 温暖   白炽灯 / 暖LED
  3200K  ████████████████  中白         卤素灯
  5000K  ████████████████  纯白 · 标准   D50 / 日光
  6500K  ████████████████  冷白 · 标准   D65 (显示标准) ◀
  9300K  ████████████████  蓝白 · 偏冷   显示器默认
  12000K ████████████████  蓝白 · 冷    阴天
  ──────────────────────────────────────────────────────
          ← 暖白(Warm)    中性(Neutral)    冷白(Cool) →

  █ 色块从橙红渐变到蓝白 (暖→冷)
  ◀ = 显示器标准白点 D65 (6500K)
```

**色温与颜色的对应关系：**

| 色温范围 | 光色 | 感觉 | 典型光源 |
|----------|------|------|----------|
| 1000~2000K | 橙红 | 极暖 | 蜡烛、火焰 |
| 2700~3000K | 暖黄 | 温暖 | 白炽灯、暖光LED |
| 3500~4500K | 中白 | 中性 | 卤素灯、自然白LED |
| 5000~5500K | 纯白 | 标准 | D50标准光源、日光 |
| 6500K | 冷白 | 标准 | D65标准白点 |
| 7500~10000K | 蓝白 | 偏冷 | 阴天、高色温显示器 |

**标准白点：**

| 白点 | 色温 | 色度坐标 (x, y) | 应用场景 |
|------|------|-----------------|----------|
| A | 2856K | (0.448, 0.408) | 白炽灯标准 |
| D50 | 5000K | (0.346, 0.358) | 印刷、摄影 |
| D65 | 6500K | (0.313, 0.329) | sRGB、显示标准 |
| D75 | 7500K | (0.300, 0.311) | 北方日光 |

> **显示器的白点设置**：大多数显示器出厂默认D65（6500K），这对应平均日光的颜色。一些显示器提供色温调节功能，用户可在暖色（低K）和冷色（高K）之间选择。色温不准确会导致整体偏色——这是显示器校准的首要参数。

**相关色温（CCT）**：当光源的色度坐标不完全落在黑体辐射轨迹上时，使用最近黑体温度作为近似色温。LED背光的白光通常由蓝光芯片+黄色荧光粉混合而成，其色度坐标可能偏离黑体轨迹，此时用相关色温描述。

## 总结：从物理原理到显示技术

本教材从五个维度系统讲解了显示技术的物理基础。五大模块之间存在紧密的逻辑联系：

1. **D1显示技术**定义了"为什么需要"——不同显示技术的优劣取舍
2. **D2光波特性**定义了"光的本质"——频率、波长、振幅、相位
3. **D3偏振光**定义了"如何控制"——LCD的核心调控机制
4. **D4几何光学**定义了"如何传播"——导光、折射、全反射
5. **D5色度学**定义了"如何感知"——颜色量化与标准

| 技术环节 | 涉及的物理模块 | 核心原理 |
|----------|--------------|----------|
| 背光导光 | D4 全反射 | 导光板内TIR传播+微结构出光 |
| 偏振起偏 | D3 线偏振 | 偏振片选择性透过 |
| 液晶调制 | D3 马吕斯定律 | $\cos^2\theta$ 灰阶控制 |
| 彩色显示 | D5 色域 | RGB三基色混色 |
| 色彩管理 | D5 色温/白点 | D65标准白平衡 |
| 亮度感知 | D2 振幅 | 光强 $\propto A^2$ |
| OLED发光 | D2 波粒二象性 | 电致发光（粒子性） |

显示技术的每一次进步，都是对光学物理原理更深层次理解和更精确应用的结果。从CRT的阴极射线发光到Micro-LED的半导体电致发光，从LCD的偏振调制到OLED的自发光，物理原理始终是技术创新的根基。
