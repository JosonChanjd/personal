# 搭一个自己的博客，把知识留下来

写博客这件事，我拖了很久。原因无他——总觉得要「准备好了」才开始。

但知识不等人，遗忘也不等人。学过的内容如果不及时写下来，很快就只剩一个模糊的印象。

## 我想要什么

- 写作是 Markdown，足够简单；
- 能全文搜索，找得到；
- 文章之间能自动关联，形成知识网络；
- 有个地方放文档和 PDF；
- 看到自己的更新频率，像 GitHub 贡献图那样。

于是有了 ByteLog。

## 记录即成长

以后每学一点东西，就写一篇；每有感悟，就记一笔。数据会替我记住走过的路。

不追求一次成型，只追求持续积累。
